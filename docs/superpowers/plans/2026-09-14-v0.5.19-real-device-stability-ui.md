# ClipGauge v0.5.19 Real-Device Stability and UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stabilize the v0.5.18 Windows workflows against observed native crashes, unsafe resource starts, model-selection drift, brittle editing context, stale status, and cluttered UI.

**Architecture:** Keep v0.5.18 sessions and artifacts compatible. Make pipeline failures typed and diagnostic-rich, make local model intent and runnable state explicit, and let the editor degrade feature-by-feature. Keep the visual surface compact and human-readable.

**Tech Stack:** Python 3.12 pipeline, React/Vite/TypeScript, Tauri/Rust, pytest, Vitest, Playwright/axe where available, Windows NSIS packaging.

**Spec:** Attached v0.5.19 real-device stability and UX correction request.

## Global Constraints

- Preserve v0.5.18 tag and historical release assets.
- Preserve existing sessions, local models, diagnostics, and user media.
- Never treat missing metadata as zero resource cost.
- Never silently change the selected local model.
- Never promote borderline output to recommended output.
- Stop before merge, tag, or release.
