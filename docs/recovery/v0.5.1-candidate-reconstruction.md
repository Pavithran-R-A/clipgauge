## Candidate identity

This is a **new authoritative v0.5.1 release candidate** based on the published v0.5.0 baseline commit `653e4139d2b45b5cd8a7527f44abc6ca20a4e54c`. ## Qualification status

The exact memory artifact, ZIP checksums, and old Debian oracle checksums were verified before use. The reconstructed diagnostics tests, Review tests, Editor tests, memory tests, and focused media-server tests must pass before expensive qualification. Full Python, frontend, Rust, security, package, model-backed, and cross-platform results belong in the release handoff and must not be inferred from the predecessor candidate.
