# v0.5.4 release-candidate ledger

This ledger separates release gates from expected pre-publication and
post-publication work. `BLOCKED` means the candidate cannot be tagged or
published. It does not mean expected metadata is defective before tagging.

## Final blocker classification

| Item | Class | Status | Evidence or closure condition |
|---|---|---|---|
| Dirty worktree | CANDIDATE_GATE | Open before commit | Commit only reviewed source, test, workflow, dependency, and release-doc changes. |
| Unpushed candidate changes | CANDIDATE_GATE | Open before push | Push the exact reviewed commit and record its remote SHA. |
| Linux candidate CI | CANDIDATE_GATE | Open before release | Required CI jobs must pass on the exact pushed SHA. |
| macOS arm64 candidate CI | CANDIDATE_GATE | Open before release | `macos-latest` qualification must pass on the exact pushed SHA. |
| macOS Intel candidate CI | CANDIDATE_GATE | Open before release | `macos-15-intel` qualification must pass on the exact pushed SHA. |
| Windows candidate installer and acceptance | CANDIDATE_GATE | Open before release | Rebuild 0.5.4 NSIS, then repeat install, upgrade, uninstall/reinstall, UI, vault, and creator checks. |
| Reachable exploitable dependency advisory | SECURITY_BLOCKER | None evidenced | VEX has per-advisory path, threat, control, and disposition evidence. Reopen if a reachable affected operation appears. |
| Product defect in mandatory workflow | PRODUCT_BLOCKER | None evidenced | Reopen if fresh candidate acceptance exposes a failure. |
| Final tagged SBOM | EXPECTED_PREPUBLICATION_STATE | Not generated yet | Generated by the immutable-tag publication workflow. |
| Final tagged SHA256SUMS | EXPECTED_PREPUBLICATION_STATE | Not generated yet | Generated from exact transferred release assets. |
| Final tagged provenance and attestation | EXPECTED_PREPUBLICATION_STATE | Not generated yet | Generated by the immutable-tag publication workflow. |
| Artifact verification after publication | POSTPUBLICATION_CHECK | Not applicable yet | Verify public assets only after publication. |
