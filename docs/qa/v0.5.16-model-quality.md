## A163 — low-resource Windows CPU ASR

Original machine: Intel Core i5-8265U, 4C/8T, 8 GB RAM, Intel UHD 620,
CPU-only. Original diagnostic ID: `diag-3d2ccb35dbf3479a`. The exact support
bundle was not supplied, so the original exception class is not claimed.

The confirmed v0.5.15 design defect was universal CPU `batch_size=8`.
The v0.5.16 path now probes
`ctranslate2.get_supported_compute_types("cpu")`, selects `int8` only when
reported, otherwise uses a supported fallback, and chooses batches of 1, 2,
4, or 8 for <=8, <=16, <=32, or >32 GiB respectively. Unknown memory stays
conservative at batch 1. CPU batches retry only allocation-shaped failures,
using a bounded halving sequence. Permanent model, runtime, and unsupported
compute failures do not retry.

Typed ASR substeps now cover runtime import, capability probe, model load,
audio load, transcription, VAD, alignment, and resource exhaustion. Safe
diagnostics include hardware, memory, pagefile, selected and actual runtime,
model revision, package versions, batch, substep, exception class, sanitized
message, and fallback attempts. Transcript text, source media, credentials,
and private paths are excluded.
