This ledger covers all 381 tracked files at audit start. Binary assets are
inventoried for ownership and packaging. Runtime-bearing sources, tests,
configuration, workflows, scripts, and behavior-defining documentation receive
targeted review. Search patterns included:

unhandled promises, stale async state, cache identity, retry and timeout
behavior, model assumptions, provider URLs, checkpoint reuse, path safety,
credential leakage, diagnostic leakage, low disk, zero output, accessibility,
and responsive layout.
