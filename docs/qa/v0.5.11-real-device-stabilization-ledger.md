# ClipGauge v0.5.11 real-device stabilization ledger

## Defect closure

| Area | Root cause | v0.5.11 closure |
| --- | --- | --- |
| Non-English ASR | Alignment stage hard-blocked every language except English. | Explicit alignment registry; English uses the verified exact asset, while Tamil and other unsupported languages use bounded deterministic fallback timings with visible status. |
| Setup readiness | Rust, Python, and UI reported different asset and runtime states. | Versioned readiness contract with installed, verified, usable, repair, selected runtime/model, and actual additional bytes. |
| Local runtime lifecycle | Download archive was treated as part of installed runtime state. | Extracted binary and version check define readiness; archive cleanup does not invalidate the runtime. |
| Runtime selection | Native inventory and Python launch could select different backends. | CUDA, then Vulkan, then CPU policy is shared by selection and launch evidence. |
| YouTube status | Stale or out-of-order events could surface a rejection card after successful ingest. | Events are scoped by job and attempt; browser-assisted compatibility is not advertised. Public download status remains separate from dependency health. |
| FFmpeg | System capability was reduced to the subtitles filter. | Readiness probes startup, subtitles, and ass filters. Managed download is offered only when needed. |
| Storage | Setup showed totals without safe, explicit cleanup boundaries. | Category breakdown plus confirmation-gated session, failed-session, safe-cache, and obsolete-runtime-archive cleanup. |
| Captions | Preset font inventory did not prove Tamil glyph preservation. | Bundled Noto Sans Tamil fallback, license notice, and preset-level Unicode regression coverage. |

## Verification matrix

- Python pipeline: full `pipeline/tests` suite.
- Frontend: Vitest and production TypeScript/Vite build.
- Native shell: formatted Rust and setup inventory tests.
- Real Windows state: installed models, extracted runtimes, system FFmpeg, path spaces, and persisted setup state are inspected before release qualification.
- Historical release: v0.5.10 remains immutable at its published commit and assets are checked independently before tagging v0.5.11.

This ledger records project-owned defects and their closure. YouTube availability remains upstream-dependent and is reported as such.

## Security audit boundaries

- `npm audit --omit=dev` reports zero advisories.
- `cargo audit` reports no actionable vulnerable release gate, but does report inherited GTK and Unicode crates as unmaintained plus one inherited GLib unsoundness advisory.
- `pip-audit` reports upstream-constrained advisories in Lightning, NLTK, and Transformers. NLTK was updated to 3.10.3; the remaining advisories have no compatible fixed version for the pinned WhisperX stack or no affected ClipGauge code path. Runtime model loading remains local, pinned, and cache-only.
- Gitleaks was unavailable on the qualification machine; repository static secret-pattern scanning was clean, and the required CI secret scan remains authoritative.
