# ClipGauge v0.6.3 Repository Audit Closure

## Scope

This repair branch starts from `826e54f2aea2c241802b3b1128b0860a65ed620d`.
It does not change the product version, release tags, or release assets.
The public `v0.6.2` release remains the stable release.

## Confirmed findings

### A. Native lifecycle authority — CLOSED

Sessions now read `runtime.json` first. The legacy `lifecycle.json` file is
read only when the runtime record is absent. A present but malformed runtime
record does not silently fall back to stale legacy state. The Windows session
fixtures now write LeaseRecord-shaped `runtime.json` files.

Evidence:

- `app/src-tauri/src/main.rs` lifecycle tests.
- `.github/windows-ui-qualification.ps1` session fixture writes.
- `.github/windows-ui-qualification-capture.test.mjs` contract test.

### B. Managed local-source resume — CLOSED

After local ingest, dependency identity uses the managed job media. Resume no
longer depends on the original picker path. Missing, changed, corrupt, or
out-of-root managed media invalidates the ingest checkpoint. Existing legacy
checkpoints receive one compatibility read, still gated by artifact checks.

Evidence:

- `pipeline/tests/test_checkpoint_dependencies.py`.
- `pipeline/clipgauge_pipeline/jobs/queue.py`.
- `pipeline/clipgauge_pipeline/ingest/stage.py`.

### C. Headless cancellation and resume — CLOSED

Pending cancellation is stored as `cancelled`, not `failed`. Running jobs keep
the cancellation marker until the stage boundary observes it. Resume removes
the marker before normal checkpoint validation. Invalid IDs, missing jobs, and
active workers are rejected. A terminal job is not reported as running after a
repeat cancellation request.

Evidence:

- `pipeline/tests/test_queue.py`.
- `pipeline/tests/test_cli.py`.
- `pipeline/tests/test_mcp_server.py`.
- `pipeline/clipgauge_pipeline/server/app.py` resume route.

### D. Local import-root authorization — CLOSED

FastAPI canonicalizes local sources and external subtitle files. Both must be
regular files inside a configured import root. Unsupported URL schemes and
hosts are rejected before yt-dlp starts.

Evidence:

- `pipeline/tests/test_server.py`.
- `pipeline/tests/test_platform_ingest.py`.
- `pipeline/clipgauge_pipeline/server/app.py`.

### E. Collection render invalidation — CLOSED

Collection title and clip-order edits clear `render_path`. The next render
must recreate the artifact for the edited collection.

Evidence:

- `pipeline/tests/test_collections.py`.
- `pipeline/clipgauge_pipeline/collections/service.py`.

### F. Collection output identity — CLOSED

Collection output names include the sanitized collection identity. Unicode,
punctuation, duplicate titles, and sanitized-name collisions do not overwrite
one another.

Evidence:

- `pipeline/tests/test_collections.py`.
- `pipeline/clipgauge_pipeline/collections/model.py`.
- `pipeline/clipgauge_pipeline/collections/render.py`.

### G. Provider JSON schema validation — CLOSED

The validator now enforces nested objects, required keys, additional-property
rules, unions, numeric bounds, string bounds and patterns, array bounds,
unique items, enums, booleans, null, and finite numbers. Errors preserve JSON
paths.

Evidence:

- `pipeline/tests/test_providers.py`.
- `pipeline/clipgauge_pipeline/scoring/providers.py`.

### H. Peak download-space accounting — CLOSED

Installed content is not counted as new download space. Missing archive assets
include their compressed download and known extraction footprint. Explicit
staging bytes remain additive.

Evidence:

- `pipeline/tests/test_v040_download_manager.py`.
- `pipeline/clipgauge_pipeline/downloads.py`.

### I. Unsupported URL classification — CLOSED

Only local files, YouTube, and Bilibili sources are accepted. Host boundaries
are explicit. Unsupported schemes and lookalike hosts fail before yt-dlp.

Evidence:

- `pipeline/tests/test_platform_ingest.py`.
- `pipeline/clipgauge_pipeline/ingest/platforms.py`.
- `pipeline/clipgauge_pipeline/ingest/stage.py`.
