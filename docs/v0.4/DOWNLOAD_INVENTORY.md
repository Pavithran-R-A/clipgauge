# ClipGauge v0.4 Download Inventory and Managed-Asset Design

This inventory records every project-owned or library-driven runtime download identified before v0.4 implementation. It distinguishes consented managed assets from user-triggered network activity and external local-runner behavior. No asset may begin downloading during a normal compute stage unless the asset is already verified and ready or the UI has paused for explicit consent with a complete size/progress plan.

## Managed asset contract

Every managed row is represented by a stable `asset_id`, immutable source URL or repository revision, expected byte size, SHA-256 or an explicit per-file snapshot integrity record, purpose, display name, license, provenance, managed destination, one-time/reuse policy, install/extraction policy, and consent group. The v0.4 manager persists state and reports `NOT_INSTALLED`, `NEEDS_CONSENT`, `QUEUED`, `DOWNLOADING`, `VERIFYING`, `INSTALLING`, `READY`, `REUSED`, `NEEDS_REPAIR`, `CANCELLED`, or `FAILED`.

Progress events must include `asset_id`, `display_name`, `operation`, `bytes_done`, `bytes_total`, `bytes_per_second`, `fraction`, `eta_seconds`, `elapsed_seconds`, `one_time_download`, `cached`, and `state`. Assets larger than 100 MB require explicit consent or a previously recorded grouped consent covering the exact asset and budget. A failed or cancelled asset is never marked verified; completed verified assets and safe job checkpoints remain reusable.

## Library-driven and user-triggered network activity

The v0.3 source also performs network operations that are not installation assets. They must remain explicit in privacy activity and must never be confused with the managed asset inventory.

| Operation | Trigger | v0.4 treatment |
|---|---|---|
| Local video file ingest | User selects a local path | No download; no consent needed; all derived files remain inside the managed job root |
| YouTube media retrieval | User pastes a URL and starts a run | Uses managed yt-dlp, managed FFmpeg path, and optional loopback PO-token provider. Network source media is not cached as a runtime asset; show source/network activity and classify errors honestly |
| WhisperX dynamic alignment language | ASR detects a language with no ready alignment model | Pause before fetch and show exact asset/size; require language-specific consent; download via manager or fail with an actionable unsupported-language state |
| Optional Pexels/Gemini visual overlays | User opens Clip Editor and requests an overlay | User-triggered media fetch, not a hidden runtime/model download. Require provider credentials where applicable, record source/provenance in the job, and keep the file job-scoped |
| Instagram OAuth/media/insight sync | User explicitly opens Instagram Loop and connects/syncs | External network integration, not setup. Never include tokens or fetched private media in support bundles |
| Ollama | User chooses external local runner | ClipGauge does not silently install Ollama. Detect `/api/version` and `/api/tags`; any model pull is an explicit user action through the official local API with streamed progress |
| LM Studio | User chooses external local runner | ClipGauge does not silently install LM Studio. Detect `http://127.0.0.1:1234/v1/models`; only offer `lms` start if safely discovered and explicitly requested |
| Cloud providers | User chooses Cloud AI and supplies a vault credential | Operation-scoped network call only; no runtime/model download is owned by ClipGauge; secrets remain in the OS vault |

## Grouped first-run plan

The normal local-file plan is calculated from actual inventory state. A typical clean setup shows Core Required (FFmpeg if no capable system binary, ASR model, English alignment data, NLTK data, and analysis models), Local AI Recommended (llama-server plus exactly one selected Qwen tier), and YouTube Compatibility only when the user chooses URL workflows. Existing verified assets are displayed as `REUSED` and contribute zero additional download bytes. The plan must include required bytes, optional bytes, installed bytes, available free space, and managed location.

The manager must never begin a >100 MB asset without either a specific consent action or a prior grouped consent that names the exact asset IDs and budget. If language is learned only after transcription, the job pauses before alignment and asks for the named model and exact size. A cancellation leaves verified prior assets untouched, removes or retains only a resumable partial according to the manager policy, and returns the workflow to a recoverable state.
